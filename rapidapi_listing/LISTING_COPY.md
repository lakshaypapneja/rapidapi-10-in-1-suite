## Long description
The all-in-one utility toolkit for AI engineers and SaaS builders. One subscription unlocks 10 production-ready endpoints:

1. Web to Markdown — turn any URL into clean, LLM-ready Markdown with token counts (RAG, AI agents).
2. B2B Lead Enrichment — extract emails, phone numbers, social profiles and tech stack from any company domain.
3. SEO & AI Search (GEO) Audit — 0-100 score with actionable issues.
4. Email Verification — syntax, live MX DNS, disposable/burner detection, typo suggestions, risk score.
5. YouTube Transcript — full transcript, timestamps, opening hook and speaking pace. No YouTube API key needed.
6. PII Redaction — strip emails, phones, SSNs, credit cards, IPs and API keys before sending text to an LLM.
7. LLM JSON Repair — fix broken JSON from ChatGPT/Claude/Gemini (code fences, trailing commas, single quotes).
8. Password & Secret Scanner — entropy, crack time and leaked API key detection.
9. Cron Parser — cron or plain English into next run times in any timezone.
10. Readability & Sentiment — Flesch score, grade level, keyword density, sentiment.

No data stored. Simple JSON. Works great with n8n, Make, Zapier, LangChain and custom agents.
